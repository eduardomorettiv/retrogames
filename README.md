# Bem vindo a Retro Games

## Descrição da atividade
Atividade de LIMA: Uma página HTML com CSS e JavaScript, que permite o usuário cadastrar jogos. Junto a um banco de dados com 3 jogos que não aparecem na página

## Tutorial:
- Clone este repositório
- Ligue o server com `node server.js` no **terminal**
- Ligue o banco de dados com o **Xampp**
